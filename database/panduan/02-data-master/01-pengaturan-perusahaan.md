Menu **Sistem → Pengaturan Perusahaan** (grup Sistem di menu samping) menyimpan identitas koperasi dan nilai awal anggota baru. Hanya grup yang punya izin menu *Company* yang bisa membukanya.

## Logo koperasi

Logo tampil di **menu samping**, **halaman login**, dan sebagai **ikon aplikasi di tab browser**.

1. Tekan **Choose File** dan pilih gambar. Pratinjau langsung muncul.
2. Tekan **Simpan Logo**.
3. Untuk kembali ke logo bawaan, tekan **Pakai logo bawaan**.

| Syarat | Nilai |
| --- | --- |
| Format | PNG, JPG, WebP, atau GIF |
| Ukuran maksimal | 500 KB |
| Saran | Gambar persegi dengan latar transparan, supaya rapi di mode terang dan gelap |

> **Catatan:** Jenis file diperiksa dari isinya, bukan dari nama file. File lain yang namanya diganti menjadi `.png` tetap ditolak. Logo BMP lama dari aplikasi desktop tidak dipakai di web karena berlatar putih.

## Nilai awal anggota baru

Kartu **Nilai Awal Anggota Baru** berisi **simpanan pokok, wajib, dan sukarela** yang dipakai sebagai isian awal saat admin menyetujui pendaftar baru di User Mobile. Admin tetap bisa mengubahnya untuk anggota tertentu di form kelengkapan. Nilai ini menentukan tagihan potongan gaji bulanan anggota baru.

- Isi angka rupiah, lalu **Simpan**. Pokok biasanya satu kali, wajib dan sukarela per bulan.
- **Kosongkan** kolom untuk memakai tebakan (nilai yang paling sering dipakai anggota baru bergrade sama).
- Perubahan hanya berlaku untuk anggota yang disetujui sesudahnya.

## Data perusahaan

| Isian | Dipakai untuk |
| --- | --- |
| Nama Koperasi (wajib, maks. 100 karakter) | Menu samping, halaman login, judul tab browser |
| Nama Manager / Ketua | Tanda tangan dokumen |
| Alamat, Alamat 2 / Telepon, Kota | Kop laporan dan nota |
| Email, Website, NPWP, SIUP, TDP | Identitas resmi |
| Biaya Adm Bank (Rp) | Ditambahkan ke potongan gaji setiap anggota aktif (saat ini Rp 2.000) |
| Pajak Pendapatan (%) | Persentase pajak pendapatan (0 sampai 100) |
| Keterangan Nota | Catatan di bagian bawah nota (maks. 1.000 karakter) |

Perubahan nama koperasi dan logo langsung terlihat di semua halaman setelah disimpan.
