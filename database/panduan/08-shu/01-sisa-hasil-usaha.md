## SHU per anggota

Pilih **tanggal tutup buku** untuk melihat hasil perhitungan SHU anggota dari aplikasi desktop:

| Kolom | Arti |
| --- | --- |
| Jasa Uang | Bagian SHU anggota kategori jasa uang, sesuai perhitungan desktop |
| Jasa Barang | Bagian SHU anggota kategori jasa barang, sesuai perhitungan desktop |
| Ke Sukarela | Bagian yang dimasukkan ke simpanan sukarela |
| Dicairkan | Bagian yang dibayarkan tunai |
| Lama (bln) | Lama keanggotaan dalam bulan |
| No. Ref | Nomor jurnal pembagian SHU |

Cari dengan kode anggota, KPK, atau nama. Jika belum ada data untuk tanggal itu, tampil *Belum ada data SHU anggota.*

> **Catatan:** Perhitungan dan posting pembagian SHU masih dilakukan di aplikasi desktop. Web menampilkan hasilnya.
